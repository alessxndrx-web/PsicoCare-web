# Recursos oficiales de Psico Care

Fuente: **Manual de Marca de Psico Care - Hackathon.pdf**, incluido en el ZIP facilitado por el usuario. El PDF tiene 52 páginas y no se añade al repositorio por su tamaño.

- `logo-light.svg`, `logo-purple.svg`, `isotype.svg`: contornos vectoriales originales de la página 1. Se retiró el fondo y las marcas decorativas periféricas. La variante morada usa el color oficial #804BDD.
- `mascot-calm.webp`, `mascot-tangled.webp`, `mascots-together.webp`: personajes oficiales de la página 29, extraídos desde los vectores con sus proporciones y colores. Se separó el fondo para conservar transparencia y se exportaron a WebP. No se generaron ni se redibujaron personajes.
- `official-mobile.webp`: recorte optimizado de la página 42, referencia de la interfaz móvil usada para construir la demo. Es una referencia de diseño, no una captura de una aplicación distribuida.
- `app/icon.png`: exportación del isotipo vectorial.

La identidad, tipografía y paleta se contrastaron con las páginas 14–29; la demo se apoya en los diseños de las páginas 41–51. Los datos personales y cifras presentes en las pantallas ilustrativas del manual no se copiaron como datos reales de producto.

Montserrat Variable y Lora se distribuyen mediante los paquetes Fontsource y conservan sus licencias incluidas en esos paquetes.
